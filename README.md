# GeoT2V video labeling

A blind labeling page for 78 short videos: 72 clips generated by text-to-video models from static-scene camera prompts, plus 6 control clips. Each clip is labeled for camera motion, changes in the scene content, image quality, and whether it could serve as a capture of one static 3D scene.

Open the page, enter your name or initials at the top, and label the clips one by one. Your labels stay in your own browser. When you are done, click "复制全部结果（JSON）" at the bottom and send the copied text to Chenrui.

The clips are shuffled and the page does not show which model made which clip.

## Build your own labeling page

The `kit/` folder turns any set of generated videos into a page like this one and compares the labels of several raters afterwards. Instructions (Chinese, with an English summary) are in [`kit/README_zh.md`](kit/README_zh.md); [`kit/PROMPT_FOR_AI_zh.md`](kit/PROMPT_FOR_AI_zh.md) is a ready-made prompt for an AI assistant that does the build and the GitHub Pages setup.
